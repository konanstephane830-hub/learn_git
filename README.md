# learn_git

Projet d'apprentissage de Git et GitHub.

## Description
Ce projet me permet d'apprendre les bases de Git, GitHub et le déploiement de sites avec GitHub Pages.

## Ce que j'ai appris
- Créer un dépôt GitHub
- Utiliser Git : add, commit, push
- Créer un fichier README.md
- Déployer un site avec GitHub Pages

## Déploiement
Site déployé avec GitHub Pages à partir du fichier index.html à la racine du dépôt, sur la branche master.
